# MASM Assembly Programs

A collection of **8086 Assembly Language programs written in MASM (Microsoft Macro Assembler)** for practicing concepts covered in Computer Organization and Assembly Language (COAL).

## Topics Covered

- Registers and Memory Segmentation
- Data Transfer Instructions (`MOV`)
- Arithmetic Instructions (`ADD`, `SUB`, `NEG`)
- Logical Instructions (`AND`, `OR`, `XOR`, `NOT`, `TEST`)
- Comparison and Conditional Jumps (`CMP`, `JE`, `JNE`, `JL`, `JLE`)
- Loops and Jump Instructions
- Arrays and Index Registers (`SI`, `DI`)
- Bit Manipulation, Shifting, and Rotation
- Flags and Signed/Unsigned Operations
- Character Input/Output Using DOS Interrupts (`INT 21H`)
- Uppercase and Lowercase Conversion
- Number System Conversions

## Purpose

This repository serves as a collection of MASM programming exercises to practice 8086 assembly instructions and strengthen my understanding of low-level programming.

## Tools

- MASM (Microsoft Macro Assembler)
- 8086 Assembly Language
